# Lennox S. Macadangdang — Portfolio

A responsive portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and footer year
- `Macadangdang_Resume_Oxford.pdf` — resume

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files in this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your portfolio will be available at your GitHub Pages URL.

No Node.js, React, Next.js, or build process is required.
